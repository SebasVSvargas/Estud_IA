# Repositorio de Prácticas - Desarrollo de Software

Este repositorio reúne todo lo trabajado en las clases de Estud-IA:

- **Desarrollo de software**
- **Frontend**
- **Backend**

## Contenido

Aquí se almacenan ejercicios, proyectos y ejemplos prácticos de los temas vistos durante el curso, incluyendo:

- Fundamentos de programación en JavaScript
- Estructuras de datos
- Programación asíncrona
- Módulos ES6
- Procesamiento de datos
- Maquetación y estilos (HTML, CSS, Bootstrap, Tailwind)
- Prácticas de organización de código y lógica de aplicaciones

## Objetivo

Consolidar en un solo lugar el avance del aprendizaje, facilitando la práctica, consulta y evolución de cada tema visto en clase.
